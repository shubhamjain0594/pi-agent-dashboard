# DOX — packages/client/src/styles

Files in this directory. One row per source file. Scoped stylesheets imported by `src/index.css` — theme CSS custom properties only, never raw hex.

| File | Purpose |
|------|---------|
| `review.css` | Cursor-style changes workspace: compact file accordions with bounded inline diffs, searchable right-side shared tree, narrow-screen stacking, source/baseline disclosure footer, theme tokens and 44px touch targets. |
| `editor.css` | Single 34px desktop inspector/actions row, 32px file tabs, compact file rows and themed scrollbars. Narrow diff controls use labelled/tooltip icons rather than stacked text rows; theme-token diff surfaces. Touch controls remain 44px. Imported by workbench.css. |
| `conversation.css` | Desktop conversation-first layout: 720px reading column, 14px/1.6 prose, compact messages, 36px session row with usage-chart overlay (no separate strip). Also styles inspector views and review/task content. Touch keeps 44px controls and in-flow actions. Imported by workbench.css. |
| `workbench.css` | Theme-token desktop workbench chrome, compact explorer (session row + exit control; closed Ended groups force `display: none` on their rows), quick-open dialog, status-bar theme controls, and responsive overview. `body:has(.desktop-workbench)` carries the same Inter/Iosevka faces onto portaled dialogs. Bundles Inter Variable for UI, Iosevka Extended for code/paths, Iosevka Term for terminals; local WOFF2 with OFL licenses. Shared 12px sidebar inset, grid-aligned project/session rows, nested session indentation, bounded 24–40px overview gutter. Installed-PWA `window-controls-overlay` drags the existing title/session/inspector rows and insets them around caption buttons. Imported by DesktopWorkbench. |
| `asciidoc.css` | `.asciidoc-body` typography scope. Styles asciidoctor embedded-output HTML (AsciiDocPreview) AND mammoth html-mode output (DocxPreview) — one shared scope (design D2). Covers heading hierarchy h1..h6 (strictly decreasing, all > 14px body), `#toc` panel + nested indent, `.admonitionblock` flattened from asciidoctor's nested table into an accent card keyed on `.note`/`.tip`/`.warning`/`.caution`/`.important` → `--severity-*` tokens, `table.frame-*`/`grid-*`/`stripes-*` attribute variants, lists/description lists, `.listingblock`/`.literalblock` code, `.quoteblock`/`.sidebarblock`/`.exampleblock`. All colors via theme vars, so `data-theme` switching retargets with no reload. NOT `@tailwindcss/typography` — that package does not know asciidoctor's class vocabulary (rejected in mockup validation); the dead `prose prose-invert` classes were removed from both wrappers. Imported by `src/index.css`. See change: asciidoc-support. |
