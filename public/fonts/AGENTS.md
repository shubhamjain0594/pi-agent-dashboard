# Bundled fonts

`iosevka/extended-{regular,italic,bold,bold-italic}.woff2`: unmodified Iosevka Extended webfonts from https://typeof.net/Iosevka/ (official site's published webfont assets, retrieved 2026-10-15).

`iosevka/term-{regular,italic,bold,bold-italic}.woff2`: unmodified Iosevka Term faces from the official v34.9.0 `PkgWebFont-IosevkaTerm-34.9.0.zip` release at https://github.com/be5invis/Iosevka/releases/tag/v34.9.0. Only these four WOFF2 files are shipped; the release archive is not bundled.

SIL Open Font License: `../font-licenses/iosevka-OFL.txt`. CSS aliases live in `packages/client/src/styles/workbench.css`. Fonts are served locally; no runtime third-party requests.
